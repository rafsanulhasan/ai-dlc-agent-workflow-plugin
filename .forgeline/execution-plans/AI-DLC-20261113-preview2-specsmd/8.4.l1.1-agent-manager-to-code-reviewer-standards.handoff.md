## Warnings
- **W1, fixed with a design choice.** A new exported `splitFlow(inner)` splits a flow list only on commas outside quotes and braces, so `"src/**/*.{ts,tsx}"` parses as one glob. A glob that contains a comma is then refused: the standard is invalid (exit 2, nothing written), and the message says to write one glob per pattern. Copilot's `applyTo` is a single comma-separated string, so such a glob cannot reach the instruction twin intact. This also answers your `applyTo` suggestion. The rule applies to block lists too.
- **W2, fixed.** Any key other than `name`, `description`, `paths` and `template` makes the standard invalid (exit 2). So does a key given twice.
- **W3, by sqa-engineer.** New cases in `tests/build-standards.test.mjs`:
  - `splitFlow` keeps braces and quoted commas together;
  - a glob with a comma is refused with exit 2 and nothing written, in a flow list and in a block list;
  - a comma-free flow list writes `paths` and `applyTo`;
  - unknown key and duplicate key each exit 2;
  - YAML-ambiguous descriptions are quoted;
  - no `.tmp` file is left behind.
