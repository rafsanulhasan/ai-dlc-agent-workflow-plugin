# Final AC text (G2 amendment D65, approved at G3)

One term is used throughout: **the standards folder**. It means the folder that `artifacts.standards` resolves to, by default `memory-bank/project/standards/`. ADR-0017 scopes the exception to exactly that folder, and naming it the same way everywhere keeps each check testable.

**New:**

**New:**

## AC-7.3 (line 133)
**Old:**

The severity is Blocker: `code-reviewer` cannot approve and `brutal-critique` returns REVISE. The rule text and the `review` skill state this check.

**New:**
- AC-7.3: When `code-reviewer` or `brutal-critique` reviews a hand-back, it raises a finding that names the file and the agent in either of these cases:
  - (a) the hand-back comes from any agent other than `documentation-writer`, and its changed paths include a file under `memory-bank/` outside the standards folder;
  - (b) the hand-back comes from any agent other than `agent-manager` (`documentation-writer` included), and its changed paths include a file in the standards folder.
  The severity is Blocker: `code-reviewer` cannot approve and `brutal-critique` returns REVISE. The exemptions in spec §14 (build-generated text such as the generated rule twins, `migrate` pure moves, `init` `.gitkeep` files) raise no finding. The rule text and the `review` skill state this check, including the standards folder case.
