# Low-level design: the preview2 contract (items 1-8 and the D22 skill move)

## 0. What this design changes in the architect's brief (also under `refine:`)
1. **Managed-block markers.** The build derives `<!-- ai-dlc:begin|end|skip <id> -->` from `PLUGIN` (`tools/build-copilot.mjs:235,244,253,261`; `PERSONA_MARKER` `:190`); `init` writes them into every consumer `AGENTS.md`, `CLAUDE.md`, `copilot-instructions.md`; rename map 3.9 omits them. 4. **`stages_completed`** must be a flat inline list of stage ids.

### 2.2 G-FM
Block at byte 0 after optional BOM: `---`, `key: value` lines, `---`; LF or CRLF. Key `^[a-z][a-z0-9_-]*$`. Value trimmed, trailing `\s+#.*$` removed. Inline list `[a, b]` → `string[]`, `[]` empty; no nesting or quoting. Lenient (hook, lens): never throws, ignores non `key: value`, last duplicate wins. Strict (`validate`): `{line, message}` for malformed and duplicates. Signature everywhere: `parseFrontMatter(text, {strict}) → { found, data: Record<string,string|string[]>, errors: {line,message}[] }`.
### 2.3 G-REC
```
record = CODE "-" AGENT "-to-" AGENT "." TYPE ".md"
CODE   = NUM *("." NUM) *(".l" NUM *("." NUM)) ["." "h" NUM]
AGENT  = [a-z][a-z0-9]*(-[a-z0-9]+)*      ; never contains "-to-"
TYPE   = handoff | handback | verdict | command | escalation
```
Hook: `CODE` (`run.ts:~204`) gains `(?:\.h\d+)?`; add `parseRecordName(name) → {code, from, to, type} | undefined` and `RECORD_TYPES`. 3. `planMove(src, dst)`: `dst` absent → `MOVE` (dir whole); both dirs → recurse (AC-11.7); both files identical → `DROP` source; both files differ → `CONFLICT {path, target}` (AC-11.5); dir vs file → `CONFLICT kind-mismatch`; reader-facing docs never a source (AC-11.8).
4. Memory folders: per catalog agent id, `ai-dlc-<id>` → `${catalog.plugin.name}-<id>` under `.claude/agent-memory/`; name built in one function (spike may change it); trivial destination (no files or empty `MEMORY.md`) counts as absent; else step-3 rule; differing `MEMORY.md` is a conflict, no keep-both mode.
5. Settings rewrite: `.claude/settings.json` and `.claude/settings.local.json` only; user-level as `advice:` lines. Textual replacement of exact JSON string literals (comments survive; `stripComments` `:681`): `"ai-dlc@ai-dlc-agent-workflow"` → `"ai-dlc-engine@ai-dlc-suite"`; `"ai-dlc@<other>"` → `"ai-dlc-engine@<other>"`; `extraKnownMarketplaces` key `"ai-dlc-agent-workflow"` → `"ai-dlc-suite"` (quoted, so a `repo` value `…/ai-dlc-agent-workflow-plugin` is untouched); `ai-dlc:<id>` → `ai-dlc-engine:<id>` via `(?<![\w-])ai-dlc:(?=<ids>)(?![\w-])` with catalog agents and skills (covers `"agent"` and `permissions` like `Skill(ai-dlc:x)`); the six lens skills by exact map first (D22): `ai-dlc:lens` → `ai-dlc-lens:show`, `lens-configure` → `configure`, `lens-init` → `init`, `lens-kit` → `kit`, `lens-keepalive` → `keepalive`, `lens-gate` → `gate`.
