# Research Findings: marketplace name `ai-dlc` and hooks-module command strings after the rename

## Q2.1 Can a marketplace be named `ai-dlc` while listing plugin `ai-dlc-engine`?
Claude Code: marketplace `name` accepts letters, digits, `.`, `_`, `-`, starts with letter/digit, no `..` [1]; `ai-dlc` not reserved (reserved: Anthropic/community names, `inline`, `builtin`, `skills-dir`, `synced`, `npm`, `pip`, `uv`, `cargo`, `github`, `gh`, `claudeai-` prefix, impersonation) [1]; docs silent on name equal to a plugin name (inferred allowed); one registered marketplace per `name` per user [1][3]; plugin name `ai-dlc-engine` valid (not `claude-`, `anthropic-`, `anthropics-`, `cc-plugin-`) [4].
Copilot: kebab-case ≤64 chars [5]; no reserved names listed; silent on name = plugin name; lookup order `marketplace.json`, `.plugin/marketplace.json`, `.github/plugin/marketplace.json`, `.claude-plugin/marketplace.json` [5].

## Q2.2 Renaming the marketplace for an existing user (docs do not document it — inference)
- Claude Code keys a marketplace by `marketplace.json` `name` [3]; `enabledPlugins` key `<entry>@<marketplace>` (today `ai-dlc@ai-dlc-agent-workflow`) [2].
- `renames` map migrates plugin names within one marketplace and rewrites `enabledPlugins` [3]; no marketplace equivalent. Changing both names together → very likely remove old marketplace, add new, reinstall.
- Removing a marketplace uninstalls its plugins and deletes their data, options and secrets [1].
- Behaviour when a registered marketplace's `name` changes on refresh: undocumented.
- Copilot: manifest `name` is the registration key; no rename command; `copilot plugin marketplace remove NAME` refused while plugins installed unless `--force` [5].
- Recommended: live test with the preview build before G2 freezes migration text.

## Q2.3 Public collisions for `ai-dlc`
- **https://github.com/TheBushidoCollective/ai-dlc** has a marketplace named `ai-dlc` listing a plugin named `ai-dlc` [6]; a user who added it cannot also add ours as `ai-dlc` [1].
- Its plugin `ai-dlc` ships `/ai-dlc:*` commands — already overlaps our current `ai-dlc` plugin namespace (supports the plugin rename).
- Similar names (no exact collision): `ijin/aidlc-cc-plugin`, `mateon01/aidlc-for-claude`, `Chorus-AIDLC/Chorus` [6].
- npm `ai-dlc`: registry 404, not definitive.
- Recommendation: do not use `ai-dlc` as the marketplace name [7].
