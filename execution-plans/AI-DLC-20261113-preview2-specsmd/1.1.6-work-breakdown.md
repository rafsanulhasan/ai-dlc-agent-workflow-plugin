# Work breakdown: preview2 (specsmd-style memory bank, bolts, typed events)

Author: James Montemagno (`product-manager`). Date 2026-11-13. Input: handoff 1.1.6, decisions-2026-11-13.md, hand-backs 1.1.1.l1.2, 1.1.3, 1.1.4, 1.1.5. Not written to the backlog. Numbering: item N = root step N of the run (N.1 planning, N.2 build, ...). Unit design (architect) and bolt design (system-engineer + architect) refine this; sizes are S/M/L/XL as in specsmd's units template.

## 1. Intent

Intent 001, preview2: restructure the ai-dlc plugin around specsmd's Inception/Construction model, adapted natively (MIT attribution to fabriqaai/specs.md), so a target repository keeps its knowledge in a two-part `memory-bank/` (`product/` for the product, `project/` for DevOps flows and agent-harness engineering), plans work as intents, units and bolts, and keeps run mechanics (execution plans per bolt, handoffs, hand-backs, run state, typed events) in `execution-plans/` instead of `docs/handoffs/`. Stage agents own the content; `documentation-writer` is the only agent that writes memory-bank files; `brutal-critique` gates them. The orchestrator still schedules; no deterministic runtime in this release. Plugin id, `ai-dlc:` prefixes, `.ai-dlc/` and `AI_DLC_*` are unchanged.
