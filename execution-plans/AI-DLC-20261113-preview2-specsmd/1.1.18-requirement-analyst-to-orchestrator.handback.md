# FR-17 and AC-17.n, final text (with product-owner 1.1.17 edits, D19–D23 and the 1.1.16 findings)

## 1. FR-17 (requirements.md)

FR-17 renames the `ai-dlc` plugin to `ai-dlc-engine` and the marketplace `ai-dlc-agent-workflow` to `ai-dlc-suite`. It also moves the lens commands into the `ai-dlc-lens` plugin (D15, D17, D19–D23; reverses D4 for these names). Both renames ship in 1.0.0-preview2 as one clean break (D23). Covers both platforms: the Claude plugin and marketplace, and the generated Copilot plugin and marketplace.

What changes:
- **Plugin name.** `name` becomes `ai-dlc-engine`; `ai-dlc:<name>` → `ai-dlc-engine:<name>`, `/ai-dlc:<skill>` → `/ai-dlc-engine:<skill>`.
- **Plugin folders.** `plugins/claude/ai-dlc/` → `plugins/claude/ai-dlc-engine/`; generated `plugins/copilot/ai-dlc/` → `plugins/copilot/ai-dlc-engine/` (D19).
- **Marketplace name.** Both marketplace files named `ai-dlc-suite` (D21). Install ids `ai-dlc-engine@ai-dlc-suite` and `ai-dlc-lens@ai-dlc-suite`.
- **Manifest fields.** Display name stays "AI-DLC Engineering Team"; keywords keep `ai-dlc` and add `ai-dlc-engine` (D20).
- **Hooks-module command names.** `ai-dlc-engine:cache-keepalive`, `ai-dlc-engine:cache-keepalive-configure`.
- **Lens commands (D22).** The six `lens*` skills move to `plugins/claude/ai-dlc-lens/skills/` and lose the "lens" prefix:

  | Old command | New command |
  |---|---|
  | `/ai-dlc:lens` | `/ai-dlc-lens:show` |
  | `/ai-dlc:lens-configure` | `/ai-dlc-lens:configure` |
  | `/ai-dlc:lens-init` | `/ai-dlc-lens:init` |
  | `/ai-dlc:lens-kit` | `/ai-dlc-lens:kit` |
  | `/ai-dlc:lens-keepalive` | `/ai-dlc-lens:keepalive` |
  | `/ai-dlc:lens-gate` | `/ai-dlc-lens:gate` |

  The human named `show` and `configure`; the other four are the orchestrator's reading, confirmed at G2. The six skills leave `tools/claude-only-skills.json` (the lens plugin as a whole is Claude-only). The lens hooks module registers the new names.
- **Lens prefix handling.** Recognises `ai-dlc-engine:`; also accepts `ai-dlc:` for one release (AC-17.11).
- **Agent memory folders.** `.claude/agent-memory/ai-dlc-<agent>/` → `.claude/agent-memory/ai-dlc-engine-<agent>/`; the platform does not document the pattern, so the spike confirms it first (AC-17.14).
- **Settings `init` writes.** `"agent": "ai-dlc-engine:orchestrator"`.
- **Every other reference.** Agents, skills, templates, generated files, tools, tests, rules and instructions, `AGENTS.md`, `CLAUDE.md`, `copilot-instructions.md`, `.claude/settings.json` (`agent`, permission paths, `extraKnownMarketplaces` key) and reader-facing docs.

**Migration.** The FR-11 migration (same entry point and dry run), in installed repositories and this one: moves the memory folders; rewrites `agent`; rewrites marketplace and plugin keys (`extraKnownMarketplaces`, `enabledPlugins`) in the repository's `.claude/settings.json` and `.claude/settings.local.json` when present. User-scope and managed settings are not touched; the upgrade guide covers them; managed `enabledPlugins` need an administrator (1.1.16 b).

**Upgrade path (D23).** No alias for a renamed plugin or marketplace (1.1.16 b) → no fallback for those names nor for old `/ai-dlc:lens*` commands. Upgrade: remove marketplace `ai-dlc-agent-workflow`, add `ai-dlc-suite`, install `ai-dlc-engine` (and `ai-dlc-lens`), run the migration. The guide warns that removing a marketplace deletes the plugin's stored data and settings.

**First construction bolt.** A spike tests the rename live, the memory-folder pattern and the moved lens commands before the migration bolt (AC-17.14).

**Does not change:** `.ai-dlc/` (incl. `.ai-dlc/lens.json`) and `AI_DLC_*` (D16); the `ai-dlc-lens` plugin name and pane ids (`ai-dlc-lens-*`); the GitHub repository name and URL (later, D17); bare agent ids in `workflow.json`; project-local memory folders (`.claude/agent-memory/<agent>/`); the "AI-DLC" lifecycle name.

**Unit assignment (D14).** Lens parts (AC-17.11, AC-17.13, lens side of AC-17.5 and AC-17.14 (c)) → ai-dlc-lens; the rest → ai-dlc-engine.

**Priority:** P1, release-gating.

**Also in requirements.md:** Decisions line "2026-11-13 (D15–D23): plugin renamed to `ai-dlc-engine` and marketplace to `ai-dlc-suite`, both in preview2 (one clean break, reinstall); plugin folders renamed; display name kept, keyword added; lens commands moved into `ai-dlc-lens` without the `lens` prefix; `.ai-dlc/` and `AI_DLC_*` kept; repository rename later." DoD: "the rename (FR-17) is complete, the spike (AC-17.14) is recorded, and this repo is migrated (AC-17.9)."
