Write the result (pass or fail, the surface, the date, the Claude Code version, and what was on screen when it failed) in the *Result* column.

The automatic tests are in `tests/keepalive.test.ts` and `tests/cache-state.test.ts`. Run `FEAT-20261020-ai-dlc-lens`, feature root 17.

## The ping counter on screen (T17.4, ITEM-035)

AC-17.4.4 (stories `docs/product/active/session-continuity-and-cache-visibility/sprint-1/keepalive-cache-status/stories.md`, US-17.4): after a ping lands, the timer callback renders the new line outside any hook event. The tests check the recorded `ui.status` call, not what the host paints. This check tells the two apart.

**Interval used for the check:** `AI_DLC_KEEPALIVE_1H_PING_EVERY=2m` in the `env` of `.claude/settings.local.json` (one developer's file, not committed, and not trust-gated). With it the 1h track pings every 2 minutes; its ping limit stays 9 and its keep-warm time 8h. Remove the variable after the check.

## Does a subagent's usage carry the 1h/5m split (T17.3c, ITEM-034.c)

AC-17.1.2 and the plan's T17.3c (`docs/plans/tier-1-sprint-1.tasks.md`, LLD `docs/specs/keepalive-cache-status.lld.md` 3.7): whether a real subagent's usage, and its transcript, say which cache lifetime its writes used. Keep-alive writes two lines to Claude Code's debug log, nothing on screen, and they change nothing else:

- `keepalive: agent usage agent=<id> split=present|absent writes=<n>`: one per model response of a subagent, as it arrives. `writes` is the response's `cache_creation_input_tokens`; `split=present` means the usage carries the `cache_creation` 1h/5m fields.
- `keepalive: subagent transcript agent=<id> rows=<n> split=present|absent`: one per finished subagent (`SubagentStop`). `rows` is the number of lines in its transcript; `split=present` means at least one row wrote to the cache with the 1h/5m fields. `rows=0 split=absent` means the transcript could not be read.

Each line in the debug log is led by the plugin's name (`ai-dlc`). Only the terminal is checked: the debug log is turned on by a command-line flag.
