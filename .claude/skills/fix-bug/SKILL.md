# Fix Bug

Use this skill for disciplined bug resolution.

## Procedure
1. Load bug context and read likely files first.
2. Identify and validate root cause before editing code.
3. Design the smallest fix that addresses the root cause only.
4. Implement without scope creep.
5. Rebuild and retest to ensure no regressions.
