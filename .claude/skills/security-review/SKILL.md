# Security Review

Use this skill for security-sensitive changes or incidents.

## Procedure
1. Identify attack surfaces touched by the change.
2. Review authentication, authorization, and input handling paths.
3. Flag data exposure and secret-management risks.
4. Report findings with remediation guidance and severity.
