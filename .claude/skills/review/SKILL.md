# Review

Use this skill as the quality gate before merge.

## Procedure
1. Load project conventions and identify review scope.
2. Review correctness and failure-path behavior.
3. Review convention adherence and dependency boundaries.
4. Review test coverage impact and gaps.
5. Report findings grouped by severity with file/line specificity.
