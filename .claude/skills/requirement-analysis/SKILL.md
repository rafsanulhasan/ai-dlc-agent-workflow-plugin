# Requirement Analysis

Use this skill to produce testable requirements.

## Procedure
1. Clarify problem and success criteria.
2. Elicit functional requirements and explicit out-of-scope items.
3. Capture non-functional constraints relevant to the request.
4. Draft acceptance criteria in verifiable form.
5. Produce a requirements artifact ready for architecture design.
