## Fixed decisions
- The codes are `AAWH` and `AAWP`, with no hyphen (the lens folder regex). Each lifecycle has `variant: "harness" | "plugin"`.
- `byType["Agent Artifact"]` is a list. Only that key may be a list. The list holds one plugin variant and at most one harness variant.
- Guards G1-G7 as in the spec. The code-review guarantee comes from the `variant` rule.
- `variant` is a CLI command whose `--json` output uses the `{ data, error }` envelope. The rule is: code or `pluginPaths` gives AAWP; docs in `harnessPaths` gives AAWH; anything else gives `ask`. Generated paths are excluded.
- `handoffReview` is a top-level key. The `handoff-review` row in `rounds` takes its own `AI_DLC_HANDOFF_REVIEW_*` variables and never the `brutal-critique` ones.
- Records are verified by the agent they are addressed to. Team mode adds the sender verifying the hand-back. The naming segment is `.h<round>`. The AAWP planning codes are N.1.1, N.1.2 and N.1.3.
- Legacy: the string `"AAW"` fails validation with the upgrade message. `merge --migrate` runs only with consent.
- Every `workflow` skill change is made by a freshly spawned agent-manager. The WF merge order is 045 → 050 → 046 → 047, and root 18's 037 and 038 follow.
