## B2: the orchestrator's avatar keeps blinking

**Root cause.** The main node's status is the main loop's own state, and main is the spawner in every run's chart. It is set to `running` at `turn.start` and `idle` at `turn.complete` (`register.tsx` turn handlers). The transcript shows one main turn running from 05:59:05 to 06:07:04, driving three runs. Task notifications and the human's own messages, the B2 report included, were queued and taken inside that one turn (`queue-operation` enqueue/remove). So once a run's agents had all finished, main was still running for the other runs, and it blinked in that finished run's chart. No turn end was missing.

**Fix.** `lens.ts:849` adds `restingSpawner`, applied in `batchView` (`lens.ts:838`). In a workflow where every member has ended, `main` is drawn `idle`: steady, never blinking. This covers every workflow chart: wide, narrow, full screen and the chat card. Any other spawner keeps its status, and so does the `/ai-dlc:lens` session chart.
