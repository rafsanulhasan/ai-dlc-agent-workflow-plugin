- Cause, confirmed from the code; which surface raised the band is unconfirmed:
  - In the VS Code narrow panel, `/ai-dlc:lens` (`openLens`, `register.tsx:1310`) opens the CHART pane inline. It does so because `onBand` (`register.tsx:1264`) is false: `bandEverywhere` (`lens.ts:2214`) needs every surface to be `terminal` or `desktop`.

  - Unconfirmed: which surface id the host gave that AbovePrompt render. `d.ts` says AbovePrompt is raised on the terminal and desktop only.
- Fix: `register.tsx:4373`: the band hook passes (`next(e)`) unless `bandEverywhere(await surfacesNow($))`, the same predicate the command uses. A session the command gives a pane never gets the band too. With surfaces unknown (`[]`), there is no band.

- Newest version: verified correct, no change. `pickRunState` (`lens.ts:2769`) reads the highest `run.v<…>.md` first (`runVersions` `lens.ts:2755`, `byVersionDesc` `lens.ts:2751`). `readRunState` (`register.tsx:681`) uses it.
- Fix: `lens.ts:1552` `runListStatus` is `workflowStatus`, with `completed` turned into `waiting` while any run it names is `active`. `workflowInfo` uses it (`register.tsx:1981`), so the run list and the band use it too.
