## Findings

### 1. What context-view shows (claudemods listing [1], repo [2])
- One meter row above the prompt, `▰`/`▱` cells. Example `42% · 84.1k/200k tokens · 82.9k until auto-compact` [1].
- Percent = last response's input tokens over model window [1].
- Estimate mode before first response: `~` prefix [1].
- Colour: warning from 6/10 of threshold, error within last 20k tokens [1].
- Past threshold: `auto-compact next`. Auto-compact off: `92.9k before the limit` then `run /compact to continue` [1].
- Meter width 20/12/8 cells by terminal width [1].
- Not shown: per-file, per-category, treemap or bar breakdown of composition [1].
- Command output: `Context view shown|hidden`, `Usage: /context-view [show|hide]` [1].
- Debug output to log via `claude --debug` [1].
- Not shown: status line, toast, pane [1].
- Source confirms `Views.band(` in the `ui.render` handler and `Awareness.noteTextOf` [4].

### 2. Events, APIs, source metadata
- Hooks: `session.start`, `classic.SessionStart`, `session.measure`, `turn.step`, `session.compact`, `classic.PostModelSwitch`, `config.set` (autoCompact), `command.run` (clear, resume, branch, autocompact, model, context-view), `ui.render` (AbovePrompt) [1].
- Calls: `$.session.usage({ breakdown: 'summary' })` and `$.session.usage()`, `$.clock.after`, `$.clock.every`, `$.store.get/set`, `$.ui.log`, `$.ui.resolve` [4][1].
- Usage is read from `const { context } = await $.session.usage()` [4]. No transcript file read was found in the fetched source; the listing does not list one.
- Reads `TERM` and `TERM_PROGRAM` to detect Ghostty [1].
- Repo: https://github.com/kongyo2/context-view, author kongyo2 [1][2].
- Licence: MIT. Copyright `Copyright (c) 2026 kongyo2` [3].
- Required Claude Code: listing says 2.1.287+ [1]; repo says 2.1.290+, tested 2.1.296 [2]. Conflict, see Open Questions.
- Install: `/plugin install context-view --marketplace kongyo2/context-view` [2].
- Size: not stated in either source. The repo has 6 commits and top-level files listed in [2].
- VS Code: not stated in either source [1][2].
- Listing footer copyright belongs to ClaudeMods, not the mod [1].
- `hooks/` folder names: `awareness`, `command`, `glyphs`, `levels`, `limits`, `message-of`, `meter`, `names`, `readings`, `views`. Contents of `meter` and `views` not fetched [2b].
