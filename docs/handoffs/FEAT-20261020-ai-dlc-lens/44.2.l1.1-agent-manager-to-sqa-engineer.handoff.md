# 44.2.l1.1 agent-manager → sqa-engineer: widened R44.4, no keep-alive band in VS Code

## Goal
Test the widened R44.4 (`44-live-findings.human.md`, *Second clarification from the human*). In the narrow VS Code view only the tabbed pane is drawn, with no band below it: neither the lens list nor keep-alive's minimised row. This round adds to 44.2 (`44.2-agent-manager-to-sqa-engineer.handoff.md`); everything there still holds.

## Cause (confirmed from the code)
- auto-handoff's `AbovePrompt` hook calls `keepaliveBand($, t, { where: 'band' })` on every render (`plugins/claude/ai-dlc/hooks/auto-handoff/register.tsx:985`).
- `keepaliveBand` checked only `settings.status` and `bandClosed`, never the surface (before this round, `keepalive.ts:528-529`).
- So where VS Code raises that site, the minimised row `⚠ ai-dlc cache-keepalive: on` was drawn below the Pane.
- As for the lens (44.2), which surface id that render carried live is unconfirmed.

## What changed
- `plugins/claude/ai-dlc/hooks/keepalive/cache-state.ts:294` `BAND_SURFACES` (`terminal`, `desktop`) and `:298` `bandEverywhere(surfaces)`: the lens's rule, copied, since the two plugins share no code.
- `keepalive.ts:518` `bandSessionNow($)`: `bandEverywhere($.session.surfaces())`; a read that fails counts as no band.
- `keepalive.ts:540`: the band site returns `undefined` unless `bandSessionNow`. The Pane site is unchanged, so its head row and its minimised form still follow R44.3.
- `keepalive.ts:1233` `openPane`: the command (`keepalive.ts:1464`) opens the Pane wherever the band is not drawn, so a session always has one view. Before, it opened only when `vscode` was attached.
- Two cases change behaviour:
  - Surfaces unknown (`[]`): the Pane now opens.
  - Terminal and VS Code attached together: no band; the Pane, as the lens does.
- The `⤢` (`anySurface`) still opens the Pane anywhere.
- No change to the lens; its band rule (44.2, `register.tsx:4373`) already covers it.
- auto-handoff's own pause panel in the same hook (`register.tsx:986`) is not keep-alive's and is untouched.
