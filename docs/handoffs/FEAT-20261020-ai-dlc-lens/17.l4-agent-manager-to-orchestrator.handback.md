**How the status is worked out** (the first rule that matches wins; the spawner is left out):
1. halted: an agent failed or was killed, or a run has `status: blocked`.
2. in progress: an agent is running.
3. teammate waiting: a teammate is `idle`, or an agent is `waiting`.
4. pending: an Agent call hasn't started, or there is no agent yet.
5. completed: everything else.

A teammate is recognised from the `teammateId` on spawn or in the list, or from type `teammate`. One change to round 4's behaviour: a teammate whose turn ends with `error` or `aborted` is now marked failed or killed. Before, every teammate stayed idle.
