## What changed
- **Blocker.** D5 adds a new pure function, `sanitiseSource(kind, source)`, with a removal list for each kind:

  - Mermaid: `click href`, `<img src>`, `![](url)`;

  Each removal adds one reason line. There is one pure-seam row per pattern. The `classify` reference in the stories is corrected.
- **M1.** Fonts are now a question for 053.a (font, licence, size). The font gets a D8 entry, and there is a fallback reason for text that cannot be drawn. ADR-0005 and the narrative are updated.
- **M2.** Both wordings of AC-20.1.1, 20.1.2, 20.1.3, 20.2.1 and 20.3.1 are in a table marked PENDING G2, and the spec says which test rows change.
