   - It logs `keepalive: agent usage agent=<id> split=present|absent writes=<n>` via `$.ui.log(..., { to: 'debug' })`. `writes` is the count of cache writes in `usage`. `split` is whether `usage.cache_creation` carries the 5m/1h split.
   - It never throws and does not write the ledger.
   - `register.tsx` `turn.step` calls it as a separate line: `if (e.agentId && r.usage) logAgentUsage($, r.usage, e.agentId)`. Do not forward to `noteUsage` and do not touch the `!e.agentId` accounting.
   - Amendment A: T17.3 makes `noteUsage` call `logAgentUsage` itself when `agentId` is set. So T17.3 removes only that one `register.tsx` call line, and the log line stays in one place.
2. `keepalive.ts` exports `logSubagentTranscript($, e: { agent_id, agent_transcript_path }): Promise<void>`.
   - It reads the path with `readRaw`, else a tail, and counts rows.
   - Amendment B: it takes `split` from a new pure `splitFromAgentTranscript(jsonl)`. This is the same as `splitFromTranscript` but keeps `isSidechain` lines (the existing function skips them at line 85). T17.3 reuses it for the fallback unchanged, so nothing is undone.
   - It logs `keepalive: subagent transcript agent=<id> rows=<n> split=present|absent`.
   - A missing path or a read failure logs `rows=0 split=absent`. It never throws and never touches the ledger.

   - It awaits `logSubagentTranscript` inside try/catch and always calls `next(e)`.
   - T17.3 keeps this handler and adds `markAgent(…, 'finished')` and the fallback after the log call.
   - Amendment C: add no `SubagentStart` or `TeammateIdle` handler and no `markAgent` before T17.3.
