## Changes (plugins/claude/ai-dlc-lens/)
1. **Decision 16, the dropped-subagent fallback.**
   - **The rule** (`hooks/register.tsx:1130-1152`, end of `refreshList`): a subagent stored `running` that `$.agent.list()` no longer lists, and that has sent no event of its own, becomes `failed` once `missingSince[id]` is `droppedSubagentMinutes` old. `endedAt` is set and the id is added to `haltedByTurn`, so a later listed `running` still resumes it.
   - **Who it covers:** subagents only, never `main` or teammates.
   - **What resets the time:** a listed row deletes the entry, so the time counts only while the agent is missing, and an agent the list still shows is never timed out. When the list throws, `refreshList` returns before this code, so no list means no timeout.
   - **Why `failed`:** the lens cannot tell a stop (`killed`) from an error, and `failed` is what a non-answer turn end showed before step 44.
   - **State:** `missingSince` (:362-368) and `heard()` (:369-372). Any event of the agent calls `heard()` and restarts the time: turn.start :4406, turn.step :4444, tool.call :4510, turn.complete :4523.
   - **When it runs:** on the existing 2 s poll, which runs while any agent is `running` (`anyAtWork`).
2. **Comment on the `listedEnded` line** (:4538-4542): a missing row counts as live, because the engine also drops finished tasks (the `agent.list` doc). Halting on it would show a working background subagent halted (ITEM-104); a dropped subagent is caught by the timeout instead.
