1. Savings / Lost to busts / NET. Confidence: High for formulas (two files agree).
- Per call: actualCost = (in·input + out·output + cacheRead·cacheRead + cacheCreate·cacheCreate)/1e6; uncachedCost = ((in+cacheRead)·input + out·output + cacheCreate·cacheCreate)/1e6. cacheSavings = uncached − actual (server/cache/analysis.ts).
- Lost to busts (bustLoss) = Σ bustLossComputed, where each event = cacheCreateTokens × max(cacheCreateRate − cacheReadRate, 0)/1e6. Null if unpriced (analysis.ts; shared/cache-lab-contract.ts).
- NET = cacheSavings − bustLoss (contract). Per session: Σ(uncached − actual) − bust loss; negative sessions counted (analysis.ts, computeSessionNets).
- Window: range {from,to}, inclusive on both ends, applied after full-stream classification (analysis.ts, callInRange). Grain hour|day|week|month (server/routes/cache-lab.ts:68-70).
- Pricing: runtime table if given, else DEFAULT_PRICING_TABLE from server/metrics/measures.ts (routes/cache-lab.ts:106).
