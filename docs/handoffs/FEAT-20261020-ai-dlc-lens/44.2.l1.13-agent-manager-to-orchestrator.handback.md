- **Rule (decision 9):** only VS Code drives the seat.
  - Only the VS Code panel's drawing of a lens pane moves the lens's seat: the place (pinned or docked), the seat `/ai-dlc:lens` lays out, the band giving way to a pane, and the Run List tab opened or closed with the seat.
