**What was merged and added**
- **New `hooks/avatar.ts` (pure functions):**
  - **Robots:** six designs (boxy, dome, cyclops, screen, octagon, can) in eight colours.
  - **Which robot an agent gets:** the 15 ai-dlc agents plus `main` come from a fixed table where no two share a robot. Any other agent type gets one from a documented stable hash, so every agent of a type gets the same robot.
  - **Image checks:** the value must be a data URI or a file path; any other scheme, including https and file:, is refused and never fetched. The type is read from the file's magic bytes (png, jpeg, gif, webp) and checked against the allowed types and the size limit.
  - **Trust check:** the trusted folders come from `~/.claude.json`, the same rule auto-handoff uses. A path counts only if its fully resolved real path is inside one of them (AC-13.9).
- **`flowchartSvg`:**
  - **Avatar styles:** robot by default, `image`, or `initials` (the old badge markup).
  - **Status:** shown as a ring around the robot; a running agent's ring blinks.
  - **Svg size cap:** an image that would push the chart over the cap is dropped, largest total first, and a dim line names it. A chart over the cap even without images is drawn as a text list (AC-12.9).
- **`register.tsx`:**
  - **Image loading:** a file path goes through the trust check, the size check and the type check, and the real path is what is read. Loaded images are cached in the module, and a new revision atom `avatarRev` makes the panes redraw.
  - **Panel headers:** show the robot or image, and keep the initials as a small label.
  - **Terminal:** draws an `Image` for a trusted PNG file path; a data URI never draws there (AC-13.5).
  - **`/ai-dlc-lens-configure`:** takes the rest of the line as the value, so paths can contain spaces; handles `avatarImage.<agent>`; refuses an untrusted or invalid image before writing anything (AC-6.5); lists refused images and why.
- **`settings.ts`:**
  - **New settings:** `avatarStyle` (robot | image | initials, default robot); `avatarImageTypes` (a list, default `image/png`); `avatarImageMaxBytes` (default 65,536).
  - **Per-agent setting `avatarImage.<agent>`:** in lens.json, `<agent>` is the agent ID for an ai-dlc agent, else the whole agent type (A21). The settings env name is `AI_DLC_LENS_AVATAR_IMAGE__<AGENT>`. It follows the lens precedence.
  - **Schema:** has a pattern entry for the per-agent keys.
