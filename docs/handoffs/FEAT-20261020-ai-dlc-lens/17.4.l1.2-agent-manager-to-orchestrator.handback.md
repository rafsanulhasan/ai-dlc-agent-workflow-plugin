## Cause
`classic.SubagentStop` (`keepalive.ts`) called `logSubagentTranscript` on every stop. That function reads the file whatever the ledger says. `agentUnsettled` only stopped the *settling*, not the *read*, and for an agent whose read gave no split it did not stop either: that agent still has only its `unknown` marker. So a second stop read the file again (Received 2, Expected 1).
