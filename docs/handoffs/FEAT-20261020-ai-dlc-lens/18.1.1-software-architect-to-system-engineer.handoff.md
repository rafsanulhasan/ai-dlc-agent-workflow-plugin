## Fixed decisions
- The taxonomy lives in its own file, `.ai-dlc/taxonomy.json`, which is optional. The plugin ships only `taxonomy.schema.json`. product-manager maintains the file.
- Ids are unique within each kind. An integration's `joins` field uses kind-qualified references.
- Tags are checked only when the file exists. An open artefact must carry `module` and `submodule`; a closed one is skipped.
- The run walk goes to depth 6, skips dot-folders and stops at a run folder. Run ids are unique across the tree. All three implementations are tested against the shared fixture `tests/fixtures/handoffs-tree/`.
- Sessions cell: `<chain short id>: <short id>, …`, with chains separated by `; `. Auto-handoff writes a `Chain:` line into the session handoff.
- `move-run` is a `workflow.mjs` command. The lens resolves a run by its id first, then falls back to `mergedHomeOf`.
- `pickRun` takes an optional `filter.module`. The setting is `runModule` (`AI_DLC_AUTO_HANDOFF_RUN_MODULE`).
- Links: a run state lists its `tasks: [ITEM-…]`, and each task carries a `- Run:` line. Both are cross-checked when the file exists.
- Merge order:
  - WF group, after root 19: 037 → 038;
  - HS group: 041 → 043 → 049;
  - RUN group: 039 → 041 → 040.
  Every change to the workflow skill is made by a freshly spawned agent-manager.
