1. **Defaults 2 / 1, not 1 / 0.** Every loop in `templates/workflow.json` carries `"maxRounds": 2, "maxFailures": 1`; `clarify` is 2 / 1. Omitted `maxRounds` → 2; omitted `maxFailures` → min(1, maxRounds − 1). That keeps old files with only `maxRounds: 1` valid (design item 3 requires it; a flat 1 would break them). Upgrade wording says loops that had no limits "are now capped at 2 rounds and 1 failure". `clarify.maxRounds` is now optional in schema and `validate`, per "the same applies to clarify".
2. **Five-level precedence per property.** `workflow.mjs` reads `env` from `.claude/settings.local.json` → `.claude/settings.json` → the process environment → the loop's value → the default. The project folder is the parent of the `.ai-dlc/` holding the file, else `--root`. JSONC tolerated (`//` and `/* */` outside strings stripped; this repo's commented `.claude/settings.json` parses with no warning). Missing file or `env` key → skipped silently; unparseable file → one warning naming it. An invalid value (wrong type or not a valid whole number) → warning naming the variable and its file (or `environment`), falls through to the next level. Settings files accept JSON numbers as well as strings. The combined check runs on the final pair; its warning names each dropped value with its source. `rounds` source column: `settings.local.json` / `settings.json` / `env` / `loop` / `default`. Docs give the order, where to set each pair, and that on Copilot only the process environment applies.
3. **New `merge --template <path> [--file <p>] [--dry-run]`.** Deep-merges, adding only missing keys from the template; never overwrites, never deletes. Arrays untouched. Stages matched by `id`: a missing stage is inserted in template order; project-only stages and lifecycles are kept. A `maxFailures` added next to an existing `maxRounds` = min(1, maxRounds − 1). Prints one `+ path = value` line per addition; writes in the template's layout (the formatter reproduces the template byte for byte — pinned by a test); then runs `validate` (or says it skipped it when there is no catalog yet). SKILL.md install and upgrade now run `merge --dry-run`, then `merge`, when `workflow.json` exists; `schema.json` and `workflow.mjs` are still replaced; `review.maxRounds` is removed only when the developer agrees.
