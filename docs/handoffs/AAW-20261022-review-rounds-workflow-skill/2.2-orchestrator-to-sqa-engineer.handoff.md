# 2.2 orchestrator → sqa-engineer: test the code paths of the configurable-review-rounds change

## Goal
The number of review rounds is now configurable, with a default of 1. Write or extend tests for the changed code so that the behaviour below is proven, then run them.

## Intent (binding)
- **New key:** `review.maxRounds` in `workflow.json`, optional, integer ≥ 1.
- **Effective limit for each loop:**
  1. env `AI_DLC_REVIEW_ROUNDS`, when it is a whole number > 0
  2. otherwise `loop.maxRounds`
  3. otherwise `review.maxRounds`
  4. otherwise 1
- **Env var handling:** unset, empty or blank means not set, with no warning. Any other non-qualifying value (`0`, `-1`, `1.5`, `abc`, `2x`, `+2`, …) is ignored with exactly one stderr warning line. Exit codes never change.
- **AAW review loops** (critique, test, code-review): `maxRounds` is no longer required. Explicit values there must still be equal.
- **New `rounds [--json]` command:** one row per stage loop (`lifecycle/stage`), with agent, loop-back target, limit and source. It refuses an invalid workflow (exit 1).
- **`show`** prints `x<N>` on every loop.
- **`validate`** must not fail because of a bad env value, and a valid env value must not make an invalid file pass.
