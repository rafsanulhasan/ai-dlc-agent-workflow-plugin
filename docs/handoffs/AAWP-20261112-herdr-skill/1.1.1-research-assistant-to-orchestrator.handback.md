# Research Findings: herdr (summary of hand-back as received)

- herdr = terminal workspace for AI coding agents (tabs/panes, per-pane agent state working/blocked/idle, persistent background server). Repo github.com/herdrdev/herdr, docs herdr.dev/docs. Apache-2.0, Rust. Latest v0.9.5.
- Windows: native support GA (ConPTY, named pipe socket); no `terminal attach`; plugins preview. Install: irm https://herdr.dev/install.ps1 | iex.
- CLI (herdr.dev/tui/docs/cli-reference): pane split --direction right|down [--cwd] [--env] [--focus|--no-focus] -> .result.pane.pane_id; tab create / workspace create [--label]; pane rename; pane focus --direction; pane close; pane run <id> <cmd>; pane send-text; pane send-keys; pane read [--source] [--lines]; pane wait-output --match|--regex [--timeout]; agent wait --until done|blocked (secondary source); api schema --json; notification show.
- Socket API: newline-delimited JSON over ~/.config/herdr/herdr.sock (named pipe on Windows); methods pane.split, pane.send_input, pane.read, agent.start, agent.wait, events.subscribe, ...
- Managed panes get HERDR_ENV=1, HERDR_SOCKET_PATH, HERDR_WORKSPACE_ID, HERDR_TAB_ID, HERDR_PANE_ID.
- Upstream agent skill skills/herdr/SKILL.md (npx skills add herdrdev/herdr --skill herdr); applies only when HERDR_ENV=1. `herdr claude` starts Claude in herdr. `herdr integration install claude` writes a state hook to ~/.claude.
- No MCP server found. No documented integration for Claude Code subagents or agent teams; panes for spawned agents would be our design on top of pane split + pane run.
