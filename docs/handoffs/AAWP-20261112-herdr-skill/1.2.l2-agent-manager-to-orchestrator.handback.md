## What changed
1. **Warning, SIGHUP** (`plugins/claude/ai-dlc/skills/herdr/scripts/herdr.mjs:720-724`, `:743`): `runChild` now has a handler, `onHangup`, registered with `process.on("SIGHUP", ...)` alongside SIGINT and SIGTERM, and removed with them after the child closes. It calls `killTree(child)`, the same as the other signals. Because the handler exists, Node no longer exits on SIGHUP by default. The wrapper waits for the child's `close` and then writes `.exit` through `finishChild` (with `usable: false`, since the child was killed). The handler also adds a no-op listener for `process.stdout` `error`. Without it, a write to the closed pane could raise an EPIPE error that nothing catches, and the wrapper would crash before writing `.exit`. That listener is my addition beyond the brief, and it is open to review.
   SKILL.md *Stopping a child* (`plugins/claude/ai-dlc/skills/herdr/SKILL.md:142`) now says that closing a pane mid-run stops the agent and everything it started, that `.exit` is still written (no usable result), and that whether herdr sends SIGHUP when it closes a pane is not verified.
2. **Suggestion, timer unref** (`herdr.mjs:642`): `setTimeout(() => signal("SIGKILL"), 5000).unref()`. If the child ignores SIGTERM it never closes, and its open pipes keep the wrapper alive, so the SIGKILL still fires in that case.
