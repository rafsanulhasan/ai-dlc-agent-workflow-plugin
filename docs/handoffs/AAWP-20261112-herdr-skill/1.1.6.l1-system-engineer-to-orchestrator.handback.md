**New detect algorithm** (LLD section 3.3):
1. `mode: off` → inactive.
2. `herdr --version` fails → inactive. This is the first herdr call, so nothing else runs without herdr on PATH.
3. `herdr status server` must show `status: running`. The exit code is ignored.
4. Anchor and source:
   - **A.** `HERDR_ENV=1`: `source:"env"`, anchor from `HERDR_PANE_ID`, else a unique match, else `null`. A `null` anchor makes `open` split with `--current`. The focused-pane `pane current` fallback is removed.
   - **B.** `HERDR_ENV` missing: reuse the run's cached `anchor.json` if its pane is still a claude pane. Otherwise run `pane list`, and keep panes where `agent=="claude"`, `agent_status=="working"`, `cwd` equals the git root or process cwd (normalised), and the pane is not one we opened (`*.pane.json`). Exactly one → `source:"pane-match"` with that anchor. Zero or two or more → inactive with a reason. Never guess.
5. Active output now carries `source` and `anchor`. `detect` takes an optional `--run`.
