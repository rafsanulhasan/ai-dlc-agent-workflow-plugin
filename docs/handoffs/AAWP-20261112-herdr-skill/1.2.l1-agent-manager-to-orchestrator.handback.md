## Deviations from the LLD
1. **The child prompt text.** I kept the 1.2 prompt, which uses only characters `safeArg` allows. The LLD's text contains `(`, `;`, `"`, `|` and `—`, which `safeArg` rejects on the `claude.cmd` path. This is unchanged from 1.2.
2. **A job file whose `root` or `out` is invalid gets no `.exit`.** Without a valid `root` and `out` there is no safe place to write it. The child prints the reason, and the parent reaches its timeout and then the fallback, which finds no copy, so the result is `stage:"run"`.
3. **`.exit` with no `sha256`** (for example a hand-written test fixture) is treated as "not matching" and goes to the fallback. This is the LLD's strict reading.
4. **`retrieveResult` reads the pane up to 3 times**, `AI_DLC_HERDR_POLL_MS` (default 500 ms) apart, but only while the markers are missing. This covers pane output that has not been rendered yet. The child also waits for stdout to flush before it writes `.exit`.
5. **`runExe` now uses `maxBuffer` 16 MiB**, for the `pane read` output.
